# Sources et dépendances

Le projet iOS initial est généré à partir du modèle de `@capacitor/cli` 8.6.0. Capacitor est distribué sous licence MIT : [ionic-team/capacitor](https://github.com/ionic-team/capacitor). Le texte de cette licence est conservé dans `licenses/Capacitor-MIT.txt`.

Les dépendances npm et Swift restent soumises à leurs licences respectives. Les fichiers de verrouillage et les versions exactes permettent d’en retrouver la provenance. Les symboles de navigation sont demandés aux API SF Symbols du système Apple.

L’icône a été générée pour ce projet ; son prompt est conservé dans `docs/ICONE.md`. Les programmes fictifs et les illustrations CSS servent uniquement à la démonstration. Aucun contenu TV, flux audiovisuel ni affiche de film tiers n’est embarqué.
