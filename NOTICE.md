# Sources et dépendances

Le projet iOS initial est généré à partir du modèle de `@capacitor/cli` 8.6.0. Capacitor est distribué sous licence MIT : [ionic-team/capacitor](https://github.com/ionic-team/capacitor). Le texte de cette licence est conservé dans `licenses/Capacitor-MIT.txt`.

Les dépendances npm et Swift restent soumises à leurs licences respectives. Les fichiers de verrouillage et les versions exactes permettent d’en retrouver la provenance. Les symboles de navigation sont demandés aux API SF Symbols du système Apple.

L’icône a été générée pour ce projet ; son prompt est conservé dans `docs/ICONE.md`. Les illustrations CSS servent de repli quand une image de programme est absente. Aucun flux audiovisuel n’est embarqué. Les horaires, résumés et images de programmes sont téléchargés depuis le guide public XML TV Fr ; ils conservent leurs droits propres. La licence Apache 2.0 du générateur XML TV Fr ne constitue pas une licence générale de ces métadonnées ou images. Voir `docs/GUIDE-TV.md`.

Les bibliothèques `sax` (traitement XML progressif), `fflate` (décompression) et `idb-keyval` (cache IndexedDB) restent soumises aux licences reproduites dans licenses/. Les versions sont verrouillées dans package-lock.json et les textes de licence correspondants sont conservés dans licenses/.
